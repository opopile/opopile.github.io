# xuyao-zhang.github.io

Personal academic homepage and research blog of **Xuyao Zhang**, hosted on GitHub Pages at [https://xuyao-zhang.github.io](https://xuyao-zhang.github.io).

## Structure

- `index.html` — Main homepage and index of research notes & open-source projects
- `style.css` — Shared clean academic stylesheet (also used by individual research blog posts)
- `.nojekyll` — Serves static assets directly via GitHub Pages without Jekyll preprocessing
- `posts/` — Research write-ups and technical notes (to be added alongside papers and code releases)
